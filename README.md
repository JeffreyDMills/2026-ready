# Toptal 2026 Ready Talent Network Framework

The standard for AI-augmented enterprise work. A tabbed, interactive view of the framework: definition, capability standard, verified curriculum, rollout plan, measurement, question bank, buyer lens, governance.

## Stack

Single static `index.html`. No build step. No external runtime dependencies. Proxima Nova and the Toptal logo are embedded as base64.

## Deploying

Vercel auto-detects this as a static site. No framework preset, no build command, no output directory.

## Updating

Edit `index.html`, commit, push. Vercel rebuilds on push to `main`. Use the `project-ship` skill from a Claude session to push updates with one command.

## Voice

Written in BASES tone — Bold, Authentic, Serious, Energetic, Succinct. Updates should hold that voice. No marketing copy, no jargon adjectives, no em dashes.
